# Changelog

## 0.2.0 - 2026-11-06

- added Story, Normal, and Nightmare difficulty modes
- added Endless Night mode and persistent best-night tracking
- added per-unit summon cooldowns
- added difficulty-based enemy and reward scaling
- improved boss scheduling for runs beyond the campaign
- cleaned up campaign and endless progression handling
- added reproducible Windows build files and public project documentation

## 0.1.0 - 2026-11-06

- initial 15-wave campaign
- sword and bow combat
- three summonable ally roles
- five enemy roles and boss encounters
- permanent upgrades, saving, abilities, sound, pause menu, and wave selection
