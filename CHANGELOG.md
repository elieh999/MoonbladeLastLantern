# Changelog

## Next update

* added sound and full screen controls
* added controller support
* added a bestiary for all enemy roles
* added four rotating wave conditions
* added combat combos and small coin bonuses
* added gameplay tests and automatic GitHub checks

## 0.4.0, 2026 11 06

* replaced the basic enemies with detailed KayKit skeleton characters
* added a different look for minions, rogues, warriors, and mages
* gave heavy enemies and bosses larger art and special colors
* added new art for the ronin, guard, archer, monk, and captain
* kept the original KayKit license and source link in the project

## 0.3.0, 2026 11 06

* added the Gate Captain as a fourth summonable ally
* added the Iron Revenant as a heavy late campaign enemy
* added six achievements with automatic coin rewards
* added persistent career totals for enemies, summons, and victories
* added a dedicated achievement screen
* refreshed the battle controls and public documentation

## 0.2.0, 2026 11 06

* added Story, Normal, and Nightmare difficulty modes
* added Endless Night mode and persistent record tracking
* added summon cooldowns for each unit
* added difficulty based enemy and reward scaling
* improved boss scheduling for runs beyond the campaign
* cleaned up campaign and endless progression handling
* added reproducible Windows build files and public project documentation

## 0.1.0, 2026 11 06

* initial 15 wave campaign
* sword and bow combat
* three summonable ally roles
* five enemy roles and boss encounters
* permanent upgrades, saving, abilities, sound, pause menu, and wave selection
