# Contributing

Thanks for helping with Moonblade.

## Start the game

Install Python 3.11 or newer. Then run:

```powershell
python -m pip install -r requirements.txt
python game.py
```

## Before sending a change

Run the tests:

```powershell
python -m unittest discover -s tests -v
```

Play at least one wave if your change affects combat or the interface.

Keep each change focused. Explain what changed and why. Screenshots are useful for visual work.

## Art and audio

Only add work that the project is allowed to share. Include the creator, source link, and license for outside assets.

## Bug reports

Include your Windows version, what you expected, what happened, and clear steps that reproduce the problem.
