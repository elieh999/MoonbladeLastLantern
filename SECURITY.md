# Security

## Supported version

Security fixes are made for the newest public version of Moonblade.

## Report a problem

Please use GitHub's private security advisory feature when a problem could put players or their computers at risk.

Include:

* the affected game version
* clear steps that reproduce the problem
* the possible impact
* any fix you already tested

Please do not publish a serious security problem before there is time to investigate it.

Normal crashes and gameplay bugs can use the public bug report form.
