# Roadmap

Moonblade is playable now, but there is plenty left to improve.

## Coming next

* character animation frames
* original music and stronger combat sounds
* controller button prompts in the battle interface
* more village scenes and battlefield maps
* more ally choices
* more boss attacks
* better settings for sound and display

## Later ideas

* challenge missions
* a second playable hero
* local save slots
* more languages
* Steam Deck testing

The order can change as the game grows.
