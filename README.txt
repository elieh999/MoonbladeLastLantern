MOONBLADE: LAST LANTERN
========================

Double-click application.exe to play. This build includes the 15-wave
campaign, three difficulty modes, and Endless Night.

Controls
--------
A / D or Arrow Keys   Move
Space / Left Mouse    Sword attack
F                     Fire bow
1 / 2 / 3             Summon Ashigaru / Archer / Monk
Q                     Storm ability
E                     Rally heal
Esc                   Pause / Back

Goal
----
Protect the Lantern Gate and defeat every enemy in each of 15 waves.
Earn coins after battles and spend them in the Village Forge. Progress
is saved automatically in your Windows Local AppData folder.

This is an original game inspired by the classic hero-led lane-defense
genre. All code, characters, names, and visual presentation are original.
